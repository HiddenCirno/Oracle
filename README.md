## 什么是Oracle？

> 一个专为SPT所设计的兼具调试和作弊功能的综合性辅助插件程序。  
在BepInEx和Harmony库共同构建的Unity-Mono生态中，所有的安装到plugins文件夹的内容都可以视为「模组」的一部分，它们以同样的继承类被加载，以同样的方式注入代码、修改游戏内容。  
而在这种条件下，我们应该如何定义作弊？又应该如何定义调试？遗憾的是，二者的界限本就模糊不清。  
所以，接下来请容我展示……我的最终之作。

## 功能介绍

**绘制层·联觉信标**

- 控制所有绘制功能的开关。

- 关闭Oracle的游戏内通知消息.

- 设置自定义准星。

- 绕过窗口捕获程序，在开启绘制的前提下，能够让窗口捕获流不显示绘制画面（管理面板和自定义准星不在此列）。

**作战部分·天堂支点**

- 通过快捷键切换自瞄（魔法子弹），你发射的子弹会自动锁定目标。

- 开火时不会消耗弹药（会自动补充一发弹药）。

- 你的武器不会因为开火而损耗耐久。

- 你的武器不会发生任何故障。

- 通过快捷键无视空间限制向面朝方向移动一定距离。

- 通过快捷键切换隐身，让AI无视你的存在。

**属性修改·生命之树**

- 你不会受到任何伤害，且不会死亡。

- 你的生命值不会因为受伤而损耗，且不会死亡。

- 你不会因为任何原因死亡。

- 奔跑、据枪、屏息等行为不再消耗耐力。

- 你携带的任何物品都不计入重量。

- 你不会因为从高处坠落而受到伤害。

- 你可以在不携带钥匙/钥匙卡的情况下打开一扇门或上锁的容器。

**透视部分·巡天星轨**

- 透视并绘制散落在地面的战利品。

- 透视并绘制在容器内的战利品。

- 透视并绘制死去的玩家/Bot的尸体。

- 透视并绘制附近的绊雷陷阱。

- 在战利品透视中高亮愿望单物品。

- 在战利品透视中高亮任务物品。

- 在战利品透视中高亮迷宫的道具（包括机关房钥匙、解谜道具以及两把固定刷新的房间钥匙）。

- 在战利品透视中高亮“生锈的带血钥匙”。

- 透视附近的玩家，以及它的信息和血量。

**虚空造物·奇迹之门**

- 通过输入物品ID，创建一个物品的实例。

- 随意复制你可以看到的任何物品的实例。

- 在战局内随意创造已有实例的复制。

- 通过可视化的面板管理已有的实例。

**战局管理·创世引擎**

- **物资管理面板：** 扫描附近的战利品，复制它们的实例，或者将它们凭空拾取。

- **Bot管理面板：** 扫描所有的存活Bot，将它们传送到你的面前（这个功能不是很好使）、打开它们的物品栏或者杀死它们。

- **Bot生成面板：** 扫描所有的AI类型，生成任意种类的AI（存在延迟且不定区域）。

- **技能管理面板：** 列出当前的技能和专精，并随意修改它们的等级。

> *以上的所有功能都可以在游戏内的F12菜单里自行调整配置，更多的细节请在游戏内自行体验。*

## 说明书

**如何使用？** 

- 在右侧的Release下载发布版本，解压后得到BepInEx文件夹，直接覆盖于游戏根目录即可。

**兼容性如何？**

- **与Fika的兼容性：** 完全兼容，我在实际测试中没有遇到任何问题。

- **与Fika.Co-op的兼容性：** 大部分功能没有问题，虚空造物的部分以Host为准，在客机下无法正常工作。

- **与Fika.Headless的兼容性：** 大部分功能没有问题，同上。
